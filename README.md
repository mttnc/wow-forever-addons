# WoW Forever Addons (personal)

Two small personal addons for **World of Warcraft: Forever**. Not published on any addon site; this repository is their public home.

| Addon | What it does |
|---|---|
| **LootLens** | Alt+Click any item (bags, loot, chat) or `/ll <name>` → drop sources with rates, vendors, quest rewards, crafting — without leaving the game. |
| **QuestLens** | `/ql` → for each quest in your log: which mob drops the item, where it is on the map, a direction arrow and a path line on the world map. |

Both addons work offline: WoW addons cannot use the internet, so the data is bundled in each addon's `Data/Data.lua`.
